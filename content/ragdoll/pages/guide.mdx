## What the description says you do

The body of the description, under the event lines, is a physics sandbox:

- Everything is destructible.
- There are 50+ weapons and gadgets “to use on ragdoll.”
- Ragdolls react to every hit, crash, and blast.
- The kit list is weapons, explosives, and toys.
- Trees, walls, towers, and cars break apart.
- A separate line just says “Fun gadgets.”
- The creators ask for feedback and update ideas, and say they read them.

That is the whole non-event pitch. It does not name a control scheme, a map list, or a multiplayer rule. The games API `maxPlayers` field was 1 on this read. A field that low on a busy experience is easy to misread, so this page does not treat it as a design statement about solo play.

The official thumbnails illustrate the same pitch. They show pale ragdolls stuck with an arrow, a spear, and throwing stars; a player character holding a chainsaw; a stone tower coming apart; a boulder on a wooden ramp; a wooden launcher tossing a ragdoll; and a tan jeep exploding into blocks. Those frames are store art. They are not a priced catalog. Credits and the CDN URLs they were saved from are in [ATTRIBUTION.txt](/images/official/roblox/ATTRIBUTION.txt).

## Zombie Rush

The description opens with a seasonal block:

> Zombie Rush Event. Kill Zombies → Collect Brains → Unlock Limited Weapons & Goblin Glider. 6 New Weapons. Goblin Glider.

In plain steps, that is the loop the developers printed:

1. Start from zombies. The text says to kill them.
2. Collect **Brains**.
3. Spend that event currency on **limited weapons** and the **Goblin Glider**.
4. The count of new weapons is **six**. Their names are not in the description.

<Callout kind="note" title="Names and dates the description skips">
November 2026 code articles name individual limited weapons and a calendar end for the event. Those names and that date are absent from the games API description read on 6 Nov 2026, so this guide does not repeat them. When the description grows a list, this page can quote it with the new timestamp.
</Callout>

Brains are described as something you collect by playing the event. They are separate from the `$1000` code line. The code does not say it grants Brains, weapons, or the glider.

## Cash, and the one number that is printed

The only dollar figure in the description is the code: **Use code SANDBOX for $1000.** How to enter it, and why a second code is not assumed from the 5k-likes line, is on [codes](/codes).

[Dexerto’s 5 Nov 2026 article](https://www.dexerto.com/roblox/ragdoll-sandbox-codes-3424970/) adds a loop the description does not: you earn Cash by getting kills, then spend it on weapons and gadgets. That sentence is Dexerto’s, dated, and useful as a report. It is not a line this site can quote from Rise To Top’s description. Shop prices, kill payouts, and a full 50-item list were not in the API text, so they are not invented here to fill the gap.

## A first session, at the level the sources support

1. Open the [place page](https://www.roblox.com/games/113398609378596/Ragdoll-Sandbox) in Roblox and join. This website cannot launch the client for you.
2. If you are there for the code, join [Rise To Top](https://www.roblox.com/groups/257996659/Rise-To-Top) first and follow the ABC-button steps on the [codes](/codes) page. The description itself only tells you the string.
3. The sandbox pitch is weapons, explosives, toys, and gadgets against ragdolls, with trees, walls, towers, and cars coming apart.
4. The event pitch is zombies, Brains, six unnamed new weapons, and the Goblin Glider.
5. The description invites feedback. It does not list a support email. This fan site does not have the developers’ inbox either. See [about](/about).
